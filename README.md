# HS Project

An open-source homeschool tracking app for families. Track curriculum progress, schedules, attendance, and records for multiple children — all in one clean, private app.

## Features

- **Family setup wizard** — add children with names, birthdays, and colour themes
- **School year configuration** — 1–7 school days per week; public school (~38 weeks), year-round, or custom schedules
- **Tabs** — Current Year, Schedule, Planning, Records, Calendar (reorderable and hideable)
- **Curriculum tracking** — chapters and named lessons with progress tracking
- **Preset curriculum library** — Logic of English, All About Reading/Spelling, The Good and the Beautiful, Singapore Math Dimensions Math, and more
- **Colour-coded year calendar** — mark school days, vacations, field trips, sick days, and more
- **Attendance tracking** — optional per child, with configurable year start month
- **Backup export/import** — save and restore your data as a JSON file

## Privacy

Your data stays in your browser. Nothing is uploaded anywhere — use the backup export/import to keep your data safe.
